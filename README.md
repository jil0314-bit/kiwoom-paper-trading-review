## 실행 경로

`3_START_V76_GUI.vbs` → `SOURCE/launcher.py` → `SOURCE/core/bot_v76_00_three_stage_ctrlv_paper.py` → 해시로 고정된 부모 모듈 → REST 데이터 / PAPER 장부 / GUI / 0600 표시 연동.

`bot_v75_*` 파일은 현재 엔트리에서 로드하는 의존 모듈입니다. 파일명에 옛 버전이 있어도 임의로 삭제하거나 단일 파일만 검토하지 마세요. 원본 매매 소스의 바이트는 변경하지 않았습니다.

## 로컬 정적 확인

Python 3.13.1로 공유본 문법을 확인했습니다. Windows GUI와 실제 Kiwoom 동작은 별도 환경에서 확인해야 합니다.

```powershell
python -B SOURCE/chain_manifest.py
python -B -m unittest discover -s tests -p test_state_manager.py
```

추가 테스트 중에는 이 공개본에서 제외한 리플레이 데이터나 로컬 검증 자료가 필요한 항목이 있습니다. 전체 테스트 통과를 주장하지 않습니다. 처음부터 시작 파일을 실행하면 인증·GUI·프로세스 동작이 발생할 수 있으므로 교차검증은 정적 읽기부터 진행하세요.

## 공개 범위

소스, 기준 문서, 기존 회귀 테스트 코드만 공유합니다. 계좌정보·API 키·토큰·환경파일·장부·실행 로그·수동 명령·개인 리플레이 데이터·백업·기존 Git 이력·ZIP은 포함하지 않습니다. 공유본의 체인 매니페스트는 포함 파일만 검사하도록 범위를 정리했습니다.

GitHub 공개 저장소이므로 누구나 코드를 읽을 수 있습니다. 모든 AI 제품의 외부 링크 열기나 GitHub 연결 기능까지 보장하는 것은 아닙니다.
